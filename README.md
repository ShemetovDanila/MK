### 2. КС-грамматика языка

1. $P \to \text{int} \ R \ P \mid \text{int1} \ L \ P \mid \text{begin} \ LIST \ \text{end}$
2. $R \to id \ ; \ R \mid \lambda$
3. $L \to id \ [ \ num \ ] \ ; \ L \mid \lambda$
4. $LIST \to A \ LIST \mid \lambda$
5. $A \to id \ X; \mid \text{if}(V) \ \text{then} \ A \ B \mid \text{while}(V) \ \text{do} \ A \mid \text{read}(Y); \mid \text{write}(S); \mid \text{begin} \ LIST \ \text{end}$
6. $X \to = S \mid [S] = S$
7. $B \to \text{else} \ A \mid \lambda$
8. $V \to S \ O \ S$
9. $O \to < \mid > \mid == \mid != \mid <= \mid >=$
10. $S \to T \ U$
11. $U \to + \ T \ U \mid - \ T \ U \mid \lambda$
12. $T \to F \ W$
13. $W \to * \ F \ W \mid / \ F \ W \mid \lambda$
14. $F \to ( \ S \ ) \mid id \ F1 \mid num \mid \text{string\_literal} \mid - \ F$
15. $F1 \to [ \ S \ ] \mid \lambda$
16. $Y \to id \ Y1$
17. $Y1 \to [ \ S \ ] \mid \lambda$

### 3. КС-грамматика в нестрогой форме Грейбах

Для обеспечения LL(1)-разбора произведена факторизация и устранение левой рекурсии.

### 5. Список операций ОПС

1.  `+`, `-`, `*`, `/`: Арифметические вычисления.
2.  `<`, `>`, `==`, `!=`, `<=`, `>=`: Операции сравнения.
3.  `=`: Присваивание значения переменной или элементу массива.
4.  `r`: Чтение значения из стандартного ввода.
5.  `w`: Вывод значения выражения или строкового литерала.
6.  `jf`: Условный переход по лжи (использует адрес и условие).
7.  `УП`: Безусловный переход по адресу.
8.  `index`: Вычисление адреса элемента массива.
9.  `neg`: Изменение знака числа.
10. `bp`: Маркер входа в исполняемый блок.
11. `ret`: Завершение исполнения программы.

### 6. Формат ОПС

*   **Структура:** Линейный массив (список) строк.
*   **Тип записи:** Постфиксная нотация.
*   **Операнды:** Строковые константы (имена), числовые литералы и строковые литералы в кавычках помещаются на стек в порядке следования.
*   **Команды:** Извлекают необходимое количество аргументов со стека и помещают результат обратно на стек.
*   **Адресация переходов:** Адреса в командах `jf` и `УП` представлены абсолютными индексами команд в списке ОПС.
*   **Инкапсуляция строк:** Строковые литералы сохраняются в кавычках для предотвращения конфликтов с именами переменных.
